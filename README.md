# alphago-policy-networks-value-networks-and-tree-search-from-scratch-in-pytorch
Mastering the game of Go with deep neural networks and tree search (Silver et al., Nature, 2016), rebuilt in PyTorch on a 5 x 5 Go board. No KGS game records are available, so the project gives you a small Go engine and a fixed Go player written in code, and its games stand in for the human expert games.
